# Scope: 2026-Phase2 — ModelStore (HuggingFace + S3 캐시)

> L2: 승인 필요 | roadmap.md Phase 2 파생 | **Created**: 2026-05-09
> **Dependency**: Phase 1 완료 후 진행

## Change Summary

HuggingFace에서 GGUF 모델을 검색·다운로드하고 S3에 캐시하는 ModelStore를 구현한다.
모델 요청 시: S3 확인 → 없으면 HuggingFace 다운 → S3 저장 → 로컬 제공.
매번 HuggingFace에서 다운받지 않음.

## 핵심 플로우

```
resolve_model("Qwen/Qwen2.5-Coder-14B-Instruct-GGUF", "q4_k_m")
  │
  ├── 1. 로컬 디스크 확인 → 있으면 즉시 반환
  │
  ├── 2. S3 확인: s3://{bucket}/models/{repo}/{filename}.gguf
  │     있음 → S3 스트리밍 다운 → 로컬 저장 → 반환
  │     없음 → 3번
  │
  ├── 3. HuggingFace API
  │     GET /api/models/{repo}/tree/main (GGUF 파일 목록)
  │     → quantization 매칭 (q4_k_m, q8_0 등)
  │     → 다운로드 URL 획득
  │     → 스트리밍 다운로드 (진행률 이벤트)
  │     → 로컬 저장
  │     → S3 업로드 (백그라운드, 논블로킹)
  │
  └── 반환: LocalModelPath
```

## 신규 모듈 구조

```
infrastructure/outbound/model_store/
├── mod.rs
├── hf_client.rs       # HuggingFace API 클라이언트
│   - search_models()
│   - list_gguf_files()
│   - get_download_url()
│   - HfModelId { repo, filename, quantization }
├── s3_cache.rs        # S3 모델 캐시
│   - exists(key) -> bool
│   - download_to_local(key, path) -> progress stream
│   - upload_from_local(path, key) -> Result (백그라운드)
├── local_store.rs     # 로컬 디스크 관리
│   - base_path: /var/veronex/models/
│   - exists(model_id) -> bool
│   - path(model_id) -> PathBuf
│   - free_space_mb() -> u64
│   - evict_lru() (공간 부족 시)
└── resolver.rs        # 전체 오케스트레이터
    - resolve_model(hf_id, quantization) -> LocalModelPath
```

## HuggingFace API

```
GET https://huggingface.co/api/models/{repo}/tree/main
→ [{type:"file", path:"model-q4_k_m.gguf", size:...}, ...]

다운로드:
GET https://huggingface.co//{repo}/resolve/main/{filename}
→ 스트리밍 (Authorization: Bearer {HF_TOKEN} 선택적)

quantization 매칭:
  "q4_k_m" → *Q4_K_M*.gguf 또는 *q4_k_m*.gguf
  "q8_0"   → *Q8_0*.gguf
  "f16"    → *F16*.gguf
```

## S3 키 규칙

```
s3://{VERONEX_MODEL_BUCKET}/models/{hf_repo_escaped}/{filename}

예:
  s3://veronex-models/models/Qwen--Qwen2.5-Coder-14B-Instruct-GGUF/
      qwen2.5-coder-14b-instruct-q4_k_m.gguf
```

## 새 환경변수

```
VERONEX_MODEL_BUCKET      # S3 버킷명 (필수)
VERONEX_MODEL_LOCAL_PATH  # 로컬 모델 저장 경로 (기본: /var/veronex/models)
VERONEX_MODEL_MAX_DISK_GB # 로컬 최대 디스크 사용량 (기본: 200)
HF_TOKEN                  # HuggingFace API 토큰 (선택, private 모델용)
```

## 새 API 엔드포인트

```
GET  /v1/models/search?q={query}&limit=20
     → HuggingFace 모델 검색 결과

GET  /v1/models/cached
     → S3에 캐시된 모델 목록

POST /v1/models/download
     { hf_repo: "Qwen/...", quantization: "q4_k_m" }
     → 202 { job_id }  (다운로드 진행 스트림)

GET  /v1/models/download/{job_id}/status
     → { status, progress_pct, bytes_downloaded, total_bytes }

DELETE /v1/models/cached/{model_id}
     → S3 + 로컬에서 제거
```
