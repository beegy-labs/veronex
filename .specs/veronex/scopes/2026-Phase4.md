## Change Summary

AIMD(Additive Increase Multiplicative Decrease) 동시성 제어를 Ollama VRAM 기반에서
llama-server slots_idle 기반으로 전환한다. 요청 부하에 따라 슬롯 수를 자동 조정하고,
슬롯 포화 시 새 프로세스 인스턴스를 자동 추가한다.

## Change Type

## 현재 vs 새 AIMD

```
현재 (Ollama VRAM 기반):
  VRAM 잔량(MB) → 모델 로드 가능 여부 판단
  /api/ps 30s 폴링 → 갱신 지연 있음
  max_concurrent: LLM 배치 분석(30s 루프)으로 조정
  KV cache MB 단위 예약·해제

새 설계 (slots_idle 기반):
  slots_idle / (slots_idle + slots_processing) → 부하율 실시간 계산
  GET /health 즉시 응답 → 지연 없음
  AIMD: 부하율 > 0.8 → parallel++ (additive increase)
         에러율 증가  → parallel *= 0.5 (multiplicative decrease)
  슬롯 포화 + VRAM 여유 → 새 llama-server 인스턴스 시작 (scale-out)
  슬롯 포화 + VRAM 없음  → 큐에서 대기 (기존 Queue 활용)
```

## AIMD 상세 알고리즘

```
30초마다 (sync loop):

for each running llama-server:
  health = GET /health
  load_ratio = slots_processing / (slots_idle + slots_processing)

  // Additive Increase
  if load_ratio > 0.8 and parallel < MAX_PARALLEL:
    new_parallel = parallel + 1
    restart_with_parallel(new_parallel)  // graceful restart

  // Multiplicative Decrease
  if error_rate > 0.1:
    new_parallel = max(1, parallel * 0.5)
    restart_with_parallel(new_parallel)

  // Scale-out
  if load_ratio > 0.95 and all_slots_full:
    if available_vram_mb > model_weight_mb + kv_overhead:
      ProcessManager.start(same_model_config)  // 두 번째 인스턴스

  // Scale-in
  if load_ratio < 0.1 and instance_count > 1:
    stop_least_loaded_instance()
```

## 스마트 모델 선택 (요청 증가 시)

```
요청 모델이 현재 미로드 상태일 때:
  1. VRAM 확인: 이 모델 올릴 공간 있나?
     있음 → ProcessManager.load_model()
     없음 → 어떤 모델 내릴까?

  2. 모델 교체 우선순위 (AIMD 정보 활용):
     - slots_processing == 0 이고 last_request가 가장 오래된 모델 선택
     - 해당 모델 프로세스 종료 (graceful, 진행 중 요청 완료 후)
     - 새 모델 시작

  3. 대기 큐 처리:
     로드 완료 → 대기 중이던 요청 자동 dispatch
```

## VramPool 단순화

```
현재: VRAM(MB) 단위 예약·해제, weight_mb + kv_cache_mb 계산
새:   slots 단위 (llama-server가 내부적으로 KV cache 관리)
      VramPool → SlotPool (provider_id → slots_idle 캐시)
      갱신: GET /health on-demand (30s max TTL)
```

## 제거 대상

| `ollama_model_repository` VRAM 프로파일 | 불필요 |
| `model_vram_profiles` DB 테이블 | 불필요 |
