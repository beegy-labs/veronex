### 8. Install Orchestrator (FSM)

- [ ] `infrastructure/outbound/model_store/install_orchestrator.rs`
  - `InstallOrchestrator { registry, blob_registry, blob_store, attempts_log }`
  - `install(model_id, source: Box<dyn ModelSource>, triggered_by)`
    1. attempts_log.start
    2. registry.update_install_status('downloading')
    3. source.resolve_sha256:
       - Some(sha) → blob_registry.find_by_sha256
         - hit → blob_registry.incr_ref + registry.update_install_status('ready') + attempts_log.succeed → 종료 (★ 네트워크 0 ★)
         - miss → 다운로드 진행
       - None → 다운로드 + 누적 sha256 → 완료 후 dedup 재확인
    4. blob_store.put (streaming + sha256 verify)
    5. registry.update_install_status('verifying') → 검증
    6. blob_registry.insert + ref_count=1 → registry.update_install_status('ready') → attempts_log.succeed
    7. 임의 단계 실패 → registry.update_install_status('failed', error) → attempts_log.fail
       **★ 자동 재시도 없음. 즉시 종료. ★**
  - `retry(model_id) -> Result<()>` — admin 호출, install_status='failed' 만 허용
  - `cancel(model_id) -> Result<()>` — 진행 중일 때 abort signal

  - error 분류 함수: `classify_error(e) -> (ErrorKind, retryable_hint: bool)`
