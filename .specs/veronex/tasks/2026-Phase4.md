- [ ] `capacity/aimd_controller.rs` 신규 — control 룰
  - `update_window(state, signals, n_parallel) -> u32`
    ```rust
    // MARS dual-condition: 한쪽이라도 overload → cut
    if (signals.u_t > 0.5 && signals.h_t < 0.2) || signals.t_t > 0.5 {
        return (state.window as f32 * 0.5).max(1.0) as u32;  // β=0.5 [Concur]
    }
    // MARS both-healthy → grow
    if signals.u_t < 0.2 && signals.t_t < 0.2 {
        return (state.window + 2).min(n_parallel);  // α=2 [Concur]
    }
    state.window  // neutral 0.2..0.5
    ```
  - control_interval: 5s (LLM TTFT jitter 흡수)
